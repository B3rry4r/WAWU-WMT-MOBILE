Decisions (Default (agent), owner may override): (a) a bucket that answers a DELETE with an error (the file is surely still there) puts the row back as it was, still counted, and the same call can be made again (the round 2 rule and its spec); a DELETE that got no answer (timeout, broken connection) may still land, so the row stays released and uncounted for the sweep to settle, and nobody can claim the key meanwhile; both answer 503 "Could not remove that file right now.
