### Findings

1. **defect (medium).** Block bypass on rooms. `GET /communities/links/:slug` and `GET /communities/:id/link` still serve a room hosted by a hidden account (id, name, `hostWawuId`) to the blocker and to the blocked person, while `GET /communities/:id` answers 404. `POST /communities/:id/join` on that room also succeeds (200), after which the member exception opens it. `GET /communities/:id/messages` on it is 403 for a non-member, a missing room is 404, so existence still shows.
2. **defect (medium).** Enumeration on the shelf. `GET /users/:id/content` for a hidden creator is 404 "User not found", but for an unknown id it is 200 with an empty list, so a caller can tell a blocked, existing person from a missing one. Profile (id and handle), piece, comments, EVG, event and professional page give byte-identical 404 bodies to a missing id (checked).
3. **defect (low).** Timing shape. Median of 30 in-process calls: hidden piece 14.5 ms against missing 6.4 ms; hidden profile 7.2 ms against 5.1 ms. The hidden path does extra queries before it refuses. Over a network the gap is small but measurable with samples. Default (agent), owner may override: accept for launch.
4. **defect (medium).** The sweep is not idempotent under overlap. `running` is an in-process flag and `fulfil()` sends the email before it claims the row. Overlapping `sweep()` x2 plus `fulfil(id)` x2 on 4 pending rows sent 5 emails. Two app instances would do the same. The row must be claimed (status update where pending) before the mail is sent.
5. **defect (low to medium).** Create race. 4 parallel `POST /settings/privacy/export` gave 4 pending rows and 4 emails; the "tapping twice gets one email" promise only holds sequentially. There is no unique constraint.
6. **defect (medium).** No rate limit on export requests. Only the global 200 per minute applies. 15 requests each fulfilled gave 15 emails in 15 sweeps, and a burst of 40 was accepted; each download also builds a 34-section file. Needs a per-user cooldown or daily cap (a number the owner or agent sets in config, recorded as PROVISIONAL).
7. **differs-for-recorded-reason (assessment, severity low to medium).** The link is a bearer token in a query string, reusable for 72 hours, signed with a key derived from `ADMIN_JWT_SECRET` by label. Tamper, expiry, wrong user and replay as an admin token all fail; reuse works by design (builder default 4). Risks: a forwarded email or a logged URL hands over the whole file for up to 72 hours; rotating `ADMIN_JWT_SECRET` silently kills every outstanding link. Default (agent), owner may override.
8. **defect (low).** The unauthenticated routes `/users/public/:id`, `/content/public/:id`, `/content/public/creator/:id/content` ignore blocks, so a blocked person can read the same data signed out. Inherent to public pages. Default (agent), owner may override.
9. **unclear (low).** `notifications` in the export carries notification text that may name other people; `data-export-sections.ts` header names `data-export.spec.ts` but the file is `data-export-map.spec.ts`. Default (agent), owner may override.
