# FIX-107 · Play a course lesson by lesson (first lesson free), and Save a course

## Current state

As of 24 Oct 2026, built by a Sonnet builder (T1), backend `wmt/FIX-107` `433e56e` and mobile `wmt/FIX-107`, both on `origin/main` (backend `0e87d06`, mobile `2847eb32`). Status verifying. No PR. A migration and routes were added, all additive.

| # | Before (`origin/main`) | After |
|---|---|---|
| 1 | a lesson row opened nothing (G-HOME-08-2, G-121): the Hub kept a lesson's title, order and length and no file | a lesson has its own file (`CourseLesson.assetKey`); a tap on a lesson plays it in the course's picture from a one-hour signed link the Hub makes for each play |
| 2 | no lesson was free unless a creator had set a preview | the first lesson of a course is always free (more when the creator opened them with the preview); a course of one lesson has none free |

| 4 | an unlocked course still drew a lock on every lesson | no lock: a play mark on each lesson with a file, the accent on the one playing |

### Backend (wawu-backend `wmt/FIX-107` `433e56e`)

- **Migration** `20261104093000_course_lesson_files_saved_courses` (later than every stamp on `origin/main` and every `origin/wmt/*`, latest was `20261102090100`): `CourseLesson.assetKey TEXT NULL`; table `SavedSchoolCourse` (unique person and course, cascade with the course). `rollback.sql` refuses while any lesson holds a file or any course is saved (both checked against a database with data, then clean, then re-applied; `migrate diff` against the migrated database is empty).
- **Routes** (new, all one segment deeper than the old catch-alls): `GET /content/:id/lessons/:lessonId/play` (403 for a locked lesson, 404 for no file or no such lesson, same 404 as the piece for a hidden or blocked one); `PUT /content/:id/lessons` (creator only: the list, the order, each lesson's file; a file must be the creator's own `content/full` upload, claimed under their storage lock; a course people have bought never loses a lesson, 409); `GET`, `PUT`, `DELETE /me/saved/courses/:courseId` (PUT and DELETE idempotent; a hidden course or school is 404 to save, drops out of Saved and the count, and comes back when shown).
- **Changed, additive**: `GET /content/:id/detail` lessons gain `hasFile`; `isFree` follows the first-lesson rule. `GET /me/saved` gains `kind: "course"` with a `course` view and the tab `courses`. No protected route changed (`test:protected` 253 pass).
- A lesson's file counts as a claimed upload (`isClaimed`), so a release or the sweep never deletes a file a lesson plays. The account purge map and the data export cover `SavedSchoolCourse`.

### Defaults (lead), owner may override

- "Enrolled" for a lesson after the first is the existing unlock: a completed purchase of the course (H25's "Unlock course"), or the creator. School courses (SC3) have no lessons; Enroll there is a different thing and unchanged.
- The first lesson is free by a platform rule, not by the creator's choice; a creator can open more (`PUT /content/:id/preview`, `freeLessons`) but never fewer than one.
- The signed link lives one hour (`LESSON_LINK_SECONDS`), asked for again on every play: long enough to seek around a long lesson, because the bucket checks the link on every range.
- A saved school course shows in Saved under All only. M30 draws no Courses chip, so none is drawn; the Hub serves `type=courses` if the designer adds one.
