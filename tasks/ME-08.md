## What the backend serves today (from the analysis)

- **M23**: served.
- **M24**: partial. Missing: The backend already accepts accessType 'free' (it is the current rules that forbid it), but it also enforces an old 'first upload must be free' rule that neither the canvas nor the current rules have. Needs the first-upload rule removed whichever way free content is ruled.
- **M25**: partial. Missing: No edit endpoint for a piece (pending or otherwise): 'You can edit it while it waits' is unsupported. 'free used' wording presumes the tick tier.
- **M37**: partial. Missing: Backend can already create, unlock-skip and count free pieces. Gap is policy, not code: the current rule forbids free content, and the first-upload-must-be-free rule must go.

A missing or partial row is yours to fix in the backend as part of this task (or the backend task listed in depends_on, check its owner in the task file). Never change the screen to fit the API.
