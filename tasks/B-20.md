- [ ] **M1**: a user can tap QR code (opens W25 'Your code'); tap Share (OS share sheet); tap Menu (M7); tap Edit profile (M8); tap own tick or verification prompt (M11); tap a social handle (opens platform externally); switch tab Content/Services/Shop/About; tap Create (+) (M19, creator accounts only).
- [ ] **M2**: a user can tap paid-messages row; tap professional listing.
- [ ] **M4**: a user can tap Add on Featured works (M36); tap a featured work (M35); tap website.
- [ ] Each artboard above matches its render in light and dark, compared picture with picture (V5).
- [ ] Every value on screen comes from the API or the user, never a literal. Anything the API does not serve yet is in `BACKEND_GAPS.md`.
- [ ] Loading, empty and error states exist and are entered by their real cause (V6).
