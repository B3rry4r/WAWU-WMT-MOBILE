A new text still mounts a new copy (a mount always reports its width); a reading of the same width changes no state, so a tick of the same width is one render and nothing it draws changes. A change of width that changes the fit shows the new text for one frame at the old fit, then at its own (seen in the live run below as heights 20 and 26).
