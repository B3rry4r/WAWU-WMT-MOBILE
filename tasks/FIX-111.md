### Backend (wawu-backend `wmt/FIX-111`)

### Defaults (lead), owner may override

- No board draws the lessons step (M21 draws one file) or the lessons editor, so both are built from existing parts (the step frame and file card of M21, the form fields of M23) with a gap row (R-29, G-FIX111-1). The wording of the step is the builder's.
- A course is made first and its lessons follow. The Hub's create call wants a full file, so the first lesson's file stands for it (`fullAsset`); the preview step (M22) stays as it was. If the lessons call fails after the course was taken, the price step keeps the draft, says so in the Hub's words, and its button reads "Save the lessons": it never makes a second course. Closing the app at that point leaves a course in review with no lessons, which Edit lessons (row 2) fixes.
- A course has at least one lesson. The Free tag shows only on the first of two or more (the Hub opens none of a course of one).
- A piece names a course when it is created. Changing or clearing it later (the edit screens) is not built.
- A course in review can be named; the row shows once the course is live.
- Editing lessons never replaces a file a lesson already has (it can give one to a lesson that has none). A removed lesson's file stays with the Hub, counted, until it is released (a low).

## Goal

A creator can build a course lesson by lesson from the app and change the lessons later, and a piece can say which of the creator's own courses it comes from, shown on H24 and opening the course.

## Scope

Backend: `prisma/schema.prisma` (the one additive migration), `src/content-piece/` (create, detail, lessons, the library query), `contract/openapi.json`. Mobile: `src/features/create/` (the lessons step and card, Details, Price, the draft, api), `src/features/library/` (the lessons editor), `src/features/content-detail/` (the row, Edit lessons), the routes `create-upload`, `create-preview`, `create-details`, `create-price`, `content/[id]`, `library/[id]/lessons`, `contract/` and `src/api/schema.generated.ts`, and their tests.
