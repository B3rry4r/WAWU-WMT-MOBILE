**Findings**

1. `unclear` (backend, pre-existing, owner or lead): handle uniqueness is case-sensitive. With `taken_one` held by another account, `PATCH /users/me {handle:'TAKEN_ONE'}` returned 200 and saved. Two accounts can then hold handles that differ only in case, and `wawu/<handle>` is ambiguous. The app is correct (it shows the Hub's 400 when the Hub gives one). Fix would be an additive case-insensitive check, but existing rows may already collide, so it needs a ruling; related to G-111. Not a regression of this task (no backend change).
2. `unclear` (low, web only): on the web build, pressing Save while the browser reports offline leaves the Save button on its spinner with no message (React Query pauses the mutation); it then sends by itself when the connection returns. On a phone React Query treats the app as online and the request fails into the "No connection" banner (shown live with a connection-refused abort), so this is expected to be web-only; confirm in V10.
3. Note (low): the Hub stores bio, location and an Instagram/TikTok/X handle as raw text (HTML, `javascript:`). The app draws it inert. Anything that later renders these as markup or builds a link from them (M1, public profile, web) must escape or validate. Pass to ME-01.
4. Note: after a handle or name is saved and the screen closes, nothing refreshes M1 yet (no M1); row #5 carries the `['profile']` key request.

**Defaults the builder listed, judged**

- Default (agent), owner may override, low: (1) counter 500 (right: contract is the fact; G-110 is the owner's call); (2) Location free text, no chevron; (3) one Name field split first word / last word / rest as middle name. A name such as "Ada van der Berg" is stored with middle name "van der", and a person whose single-word name was set elsewhere cannot re-save that field as one word; both follow from G-112 (owner); (4) M8 rows open M9, Back and Done keep the draft, only Save sends; (5) handle cannot be emptied once set, format checked only when changed; (6) picture uploads on choose, saved with Save, phone has no camera buttons until the picker is installed; (7) toast 1.2 s then M8 closes; (8) discard prompt; (9) social entries take a handle or a pasted link; (10) save is two requests, a retry sends the rest; (11) no cross-visit caching.
