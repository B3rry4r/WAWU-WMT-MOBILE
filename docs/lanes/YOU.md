# Lane: YOU (owner)

You run the project and build the parts nothing else waits on.

## Running the project

- **Decisions.** Rule the open rows in `DECISIONS.md`. D1 to D4 first (task
  Y-01). Each ruling names the tasks that carry it out.
- **Hand out tasks** with the one-line prompts in `tasks/INDEX.md`. Builder and
  verifier are always different sessions, including for your own tasks.
- **Shared changes.** Between waves, apply the rows in `SHARED-CHANGES.md`
  yourself (theme, shared components, routes, schema) and move each to
  "Applied" with what was actually done.
- **Review.** A pull request merges only with its evidence pack. Look at the
  screenshots yourself: machines catch crashes, a person catches "this looks
  wrong".
- **Close stages** (tasks G-0 to G-9) after the stage audit.
- **Outside the team:** Fintava (Y-02), the designer (Y-05), store accounts.
