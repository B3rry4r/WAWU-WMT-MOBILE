## Failures for fix tasks (our code, precise)

All three below were fixed by FIX-97 (backend `wmt/FIX-97`) and re-run on dev on 23 Oct; see the two NUV-06 rows above.

- **NUV-06 name check, request** (`src/nuvion/areas/payouts.ts` lines 291-297 at `13e27536`): the body must be `{country: "NG", account_number, issuer: {code: <bank code>}}`; ours sends `bank_code` and gets 422 "issuer required".
- **NUV-06 name check, reader** (`readLookup`, same file, lines 1343-1356): the real answer is `data.details.name` and `data.details.account_number` (with `status: successful`, `status_reason: successfully_resolved`, `meta.routability`); the reader sees none of them. A missing account answers 404 `error_resource_not_found`, which the switch at about line 301 does not map to "not found". Dev resolves bank 044, the test account ending 0031 (name "Forrest Green") and nothing else tried.
- **NUV-06 counterparty** (`createCounterparty`, same file, lines 899-914): an individual needs `profile.email` and `profile.address` (`line1`, `city`, `country`); without them every bank send stops with 422. Which email and address WAWU sends for a payee is a ruling.
