## API Reference: Customer
- [Create Customer](https://fintava.readme.io/reference/create.md): This endpoint helps you create new customers. The parameters needed are the customer's personal data and the funding method. See the information section in this endpoint to get more insight on what…
- [Get customer list](https://fintava.readme.io/reference/get-customer-list.md): This endpoint will get you the list of all the customers that belong to a merchant
- [Get customer by phone](https://fintava.readme.io/reference/get-customer-by-phone-number-not-available-yet.md): You can get a customer's details, by inputing their phone number
- [Fetch Customer](https://fintava.readme.io/reference/create-customer-copy.md): This endpoint helps you get the details of a specific customer. The only parameter needed for this operation is the customer ID. You can get the customer ID by running the Get customer list endpoint.

## API Reference: ACCOUNTS & WALLETS
- [Get merchant's wallet balance](https://fintava.readme.io/reference/wallet-balancepending.md): This endpoint returns a merchant's wallet balance
- [Wallet Balance](https://fintava.readme.io/reference/unfreeze-wallet-copy.md): This endpoint helps you get the wallet balance of a particular customer. The only parameter needed for this is the walletId. The walletId is created after you run the create customer endpoint…
- [Get Wallet Details](https://fintava.readme.io/reference/get-wallet-details.md): Get the details of any wallet on fintava.
- [Get Account Details](https://fintava.readme.io/reference/get-account-details.md): Get the account information of external account number from other banks
- [Freeze Wallet](https://fintava.readme.io/reference/freeze-customer-wallet.md): This endpoint freezes a customer's wallet, disabling all financial transactions.
- [Unfreeze Wallet](https://fintava.readme.io/reference/freeze-customer-wallet-copy.md): This endpoint unfreezes a customer's walletId allowing them to perform financial transactions.

- [Transfer to bank](https://fintava.readme.io/reference/bank-credit.md): This endpoint enables funds transfer from a customer's wallet to a bank.

- [Wallet Transfer](https://fintava.readme.io/reference/wallet-transfer.md): This endpoints allows transfers between two Fintava wallets.

## API Reference: transactions

- [Get Customer Transaction](https://fintava.readme.io/reference/customer-transaction.md): Get all the transactions that occurred on a specified customer's wallet
- [Get Transaction by id](https://fintava.readme.io/reference/get-transaction-by-id.md): Use this endpoint to search for a transaction using the transaction id
- [Get Transaction by Reference](https://fintava.readme.io/reference/get-transaction-by-reference.md): Get details of a transaction by searching for it with it's reference.

- [Verifying Events](https://fintava.readme.io/reference/verifying-events.md): Verifying webhook events come from Fintava is necessary to avoid creating transactions due to a fraudulent event.  To verify events, validate the x-fintava-signature header sent with the event
