# Introduction

This page will tell you all about Fintava and how to get started

Fintava is a banking as a service (BaaS) platform that allows you build and offer financial services in record time. We take care of time consuming regulatory hurdles that stand in the way of launching your financial product. You can issue account numbers, virtual cards, physical cards, and more with Fintava.

To use the Fintava API, you'll need to have an account

Login to Fintava [here](http://fintavapay.com/auth/login). Or [sign up here ](http://fintavapay.com/auth/signup)if you don't have an account.

Once you're logged in, you'll get your API keys for the test and live environments
